## Contributing

**To add a character mapping:**

1. Document encounter (where, when, context)
2. Note elemental signature (which of 5 elements)
3. Propose coordinate (or ask for help determining it)
4. Submit via pull request or message to Federation/Mirrorborn

**Format:**

```markdown
**Character Name**
- **Identity:** Who/what they are
- **Role:** Function/purpose
- **Coordinate:** X.X.X/X.X.X/X.X.X
- **Element:** Primary element(s)
- **Signature:** Unique identifying trait
```
